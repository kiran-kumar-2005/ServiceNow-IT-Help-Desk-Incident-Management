# ServiceNow IT Help Desk Incident Management System

## 📌 Project Overview

The **ServiceNow IT Help Desk Incident Management System** is an IT Service Management (ITSM) project developed using **ServiceNow Zurich**.

The system is designed to manage IT incidents from creation to resolution. It automates incident assignment, provides team notifications, tracks resolution using an SLA, and provides analytics through reports and dashboards.

## 🎯 Objectives

- Manage IT incidents efficiently.
- Automatically assign incidents to the appropriate support group.
- Notify support teams when relevant incidents are assigned.
- Track incident resolution within a defined SLA.
- Monitor incident status using reports and dashboards.
- Understand and implement ServiceNow ITSM concepts in a practical scenario.

## 🛠️ Technologies Used

- ServiceNow Zurich
- IT Service Management (ITSM)
- Incident Management
- Assignment Rules
- Provider Notifications
- SLA Management
- Reports
- Platform Analytics
- ServiceNow Tables, Forms and Lists

## ⚙️ Key Features

### 1. Incident Management

The system allows users to create and manage incidents with important information such as:

- Caller
- Category
- Subcategory
- Short Description
- Description
- Impact
- Urgency
- Priority
- Assignment Group
- Assigned To
- State
- Work Notes
